# YellowTaxi - Projeto de Análise de Dados de Táxis de Nova York
Projeto de análise de dados utilizando registros de táxis amarelos de Nova York para explorar padrões de viagens, tarifas, tendências temporais e insights geoespaciais por meio de limpeza, transformação e visualização.

# Licença
Este projeto tem fins educativos. Sinta-se à vontade para usar e adaptar o conjunto de dados para aprendizado e análise.

# Visão Geral
Este projeto analisa o conjunto de dados dos táxis amarelos de Nova York para compreender o comportamento das viagens, os padrões de preços, as tendências temporais e a distribuição geográfica. O trabalho inclui limpeza de dados, engenharia de recursos, análise exploratória e visualizações que fornecem informações sobre as operações de táxi na cidade de Nova York.

# Objetivos
- Limpe e prepare o conjunto de dados Yellow Taxi para análise.
- Explore a duração da viagem, a distância, as tarifas e os padrões de passageiros.
- Identificar tendências temporais (horárias e diárias).
- Analise o comportamento espacial usando os locais de coleta.
- Gere informações visuais que apoiem as decisões operacionais e de negócios.

# Principais características
- Limpeza de dados (remoção de registros inválidos, correção de tipos de dados).
- Criação de métricas adicionais, como tarifa por milha e indicadores de horário de pico, para apoiar a análise.
- Análise de séries temporais de viagens e receitas.
- Mapeamento geoespacial de zonas de recolha.
- Painéis visuais que destacam tendências e KPIs.
